# Green Fish · dados

Base fundiária usada pelo app Green Fish (https://jpribeiro-aqua.github.io/green-fish/):
imóveis certificados no INCRA (SIGEF e SNCI) e assentamentos, em blocos de 1° × 1° por estado (`data/reg/uf_lat_lon.json.gz`) com um índice por estado (`data/reg/uf_index.json`).

Os dados ficam neste repositório separado para que cada atualização do app seja publicada rapidamente.
Fonte: INCRA (Acervo Fundiário / SIGEF / SNCI). Sem nomes de proprietários nem CPF/CNPJ.
